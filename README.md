# Mijn Nijmegen Gemachtigd

Voor nu alleen dev en accp gemaakt. 

Omgeving voor gemachtigden zoals bewindvoerders die alleen de informatie en taken kunnen zien en berwerken die in scope liggen.
Deze repository werkt samen met Mijn Nijmegen. Daar kan de gemachtigde op inloggen drukken, waarna doorverwezen wordt naar deze omgeving. 

- Eigen authenticatie
- Eigen sessiebeheer
- Eigen cookie
- Eigen home, nav
- Overzicht van de scopes van de gemachtigde en wat dit betekent
